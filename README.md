# 🚀 Master Developer Hub — Backend & Learning Roadmaps

Designed & Developed by **Pratik Raj** ([@PRATIKRAJSONU](https://instagram.com/PRATIKRAJSONU))

Complete 7-Track Developer Roadmap Web Application with Python SQLite Backend server, interactive progress tracking, YouTube playlists, downloadable PDF study notes, and Admin management portal.

## 🚀 Features
- 🤖 **AI / ML & Python Master Track** (80 Days)
- ⚡ **Backend Engineering Master Track** (60 Days)
- 🗄️ **SQL & Databases Track** (15 Days)
- 🎨 **Web Development Track** (20 Days)
- ☁️ **Cloud Platforms Track (AWS/Azure/GCP)** (20 Days)
- 🗄️ **Complete DBMS & Database Engineering** (60 Days)
- 🏗️ **System Design — Beginner to Advanced** (60 Days)
- 🔐 **Admin Management Portal** for updating playlists, uploading PDF notes, and managing user accounts.

## 🛠️ Local Server Execution
```bash
python3 server.py
```
Backend runs at `http://localhost:5000`.
